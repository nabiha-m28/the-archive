# The Archive

- Built a full-stack web application, The Archive, that lets users describe a designer fashion item and it finds it across resale platforms
- Integrated LLM and search APIs to score and rank scraped marketplace listings against the search query, filtering out mismatched results
- Built Supabase-backed user authentication and a persistent wishlist feature, syncing user profile data and saved items across sessions


## Features

- Describe any designer fashion item and find it (or the closest match) across resale platforms
- Filter results by price
- Save listings to a wishlist with Supabase-backed user accounts
